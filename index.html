Enquiry Form Brief

The field changes, layout and newsletter split for the package enquiry form, ready to pass to Synapse. A first step in building clean lists and data in Fresh.

1At a glance

What we're changing and why, in one view.

The form works today, so this is a tidy-up, not a rebuild. The aim is that every enquiry arrives in Fresh with clean, usable details, so the team spends less time asking the customer things they already told us, and we can start building our marketing lists properly. The form stays custom built, and the Zapier connection carries the data through.

Today

  • Children's ages typed into one small free-text box
  • Departure point already shows "Self-Drive", so it's easy to send without choosing
  • Departure options limited to Johannesburg, Cape Town, Durban, Self-Drive and Other
  • One "Sign up for more travel deals" tick that isn't a real subscription in Fresh
  • Fields sit in a three-across grid that gets cramped on a phone
  • Package page link not reaching Fresh

Proposed

  • Pick the number of children, and an age box opens for each child
  • Departure point starts blank and must be chosen
  • Added: Port Elizabeth (Gqeberha), East London, Bloemfontein
  • Newsletter tick creates a separate marketing subscription, with the interest picked up from the page
  • Expanded sign-up flows to Fresh too: travel agents kept apart, 14 interests grouped into 6 themes, two lists only
  • The footer sign-up link shared by Tommy and the team
  • Grouped sections, one column on mobile, bigger tap areas
  • Hidden fields carry the page link, reference, property name and destination
  • A clickable Package Link on every enquiry, so consultants see the full package in one click
  • Every enquiry named the same simple way: Hotel or Destination - Surname
  • All newsletter forms on the site brought in line with one standard form

4Children's ages

How the per-child age boxes should behave.

Behaviour

Number opens the boxes

Choosing 3 in Children shows Child 1, Child 2 and Child 3 age boxes. Changing it to 1 removes the extra two. 0 shows nothing.

Options

Ages as a dropdown

"Under 2", then 2 to 17. No typing, so the data always arrives the same way.

Wording

Age on the travel date

Small hint under the boxes: "Age on the date of travel". Many package prices change at a birthday.

Rule

Ages required

If children are selected, each age must be chosen before sending.

More than 6 children? The dropdown stops at 6 and a small line reads "Travelling with more? Add the details in the message." Large groups are rare and best handled by a consultant anyway.

How it arrives in Fresh

Rather than six separate age fields, I'd suggest the ages are combined into one tidy line, plus two helpers that make reporting and lists easy:

6Enquiry names

Simple, and easy to spot in the pipeline at a glance.

The format: Hotel or Destination - Surname. The hotel always comes first when we know it, because "Oyster Box" tells a consultant far more than "KZN". The surname makes it easy to find the right enquiry when a customer phones in. Status lives in the pipeline stage, and dates, reference and page link live in their own fields, so the name doesn't need to carry them.

How the name is built

1. Property nameIf the page is a hotel or package, use the short property name.
→
2. DestinationIf there's no property (a destination or deals page), use the destination.
→
3. GeneralIf neither, use "General". The consultant renames it once the hotel is known.

Synapse sends the short property name and the destination as hidden fields from the package details the site already holds, and Zapier puts the name together before the enquiry lands in Fresh. We don't work it out from the web address, because the address runs the hotel and destination together with no break between them.

7Newsletter split

Keeping enquiries and marketing subscribers apart, while both reach Fresh.

An enquiry and a newsletter sign-up are two different things, even when the same person does both. The enquiry is them asking us for something. The newsletter is permission to market to them. They need to stay separate so we can respect opt-outs and POPIA, and so the enquiry follow-ups don't get mixed up with marketing.

Two ways people subscribe

Enquiry form tickCustomer ticks "Send me travel deals" while enquiring.
→
Zapier checks the tickEnquiry always goes to Fresh. Only if ticked, a subscription is added too.
→
FreshContact + Enquiry, and (if ticked) added to the matching list.
Newsletter sign-up formThe full sign-up on the site, or the sign-up page linked in the footer.
→
ZapierNo enquiry created. Subscription only, with the page it came from.
→
FreshMarketing contact, added to the matching list.

The two forms side by side

Enquiry form tick (simple)

  • One tick box, nothing else asked
  • We already have name, email and phone from the enquiry
  • Interest is picked up quietly from the page link (see below)
  • Stays simple on purpose; the enquiry is the main job of this form

"Sign up to our exclusive travel deals" (expanded)

  • 14 interest tick boxes, from Beach Destinations to Sports Travel

The audience split: Travel Agent = Yes

Travel agent sign-ups are kept separate from holiday customer sign-ups. When "Are you a Travel Agent?" is Yes, Zapier places them in their own Travel Agent list, with the same details. When it's No, they go to the Travel Deals Subscribers list as normal.
Keeping them separate: travel agent sign-ups sit in their own list and are not included in any Thompsons For Travel customer communication. This keeps the two audiences clearly apart and means their details are looked after properly.

Picking up the interest from the page (enquiry tick only)

For the simple tick, splitting on the page link makes sense, as long as we keep it light. The site already separates Destinations from Local Destinations in its menu, and the page link usually names the destination. So the tick can quietly pick up:

  • Local or International, from which part of the site the page sits in
  • The destination where the page names one (e.g. a Mauritius package page)
  • Family where the enquiry includes children

The expanded sign-up doesn't need this as much, because the customer tells us their interests directly, but we'd still capture the page link so we know where sign-ups come from.

Alongside Mailchimp: the expanded sign-up keeps sending to Mailchimp as it does today, and Zapier also sends each sign-up to Fresh.

One newsletter form across the site

There are a few different newsletter sign-up forms on the site today. They should all collect the same details in the same way, so every sign-up arrives in Fresh complete and goes to the right list, whichever page it came from. The full "Sign up to our exclusive travel deals" form becomes the one standard, and every other version is brought in line with it.

8Lists in Fresh

A small set of lists, with the detail held in fields rather than in more lists.

The principle: lists are for who has said yes; fields are for what they're interested in. If we made a list for every destination we'd end up with dozens to maintain. Instead, a few lists plus a couple of interest fields let us pull any group we need later (for example, "international subscribers interested in Mauritius with children") as a saved view, without anyone building a new list.
List 1 · Customers

Travel Deals Subscribers

Every holiday customer who has opted in, from either form. The one master marketing list, and the one opt-outs are managed against.

List 2 · Travel agents

Travel Agent Subscribers

Anyone who answered Yes to "Are you a Travel Agent?". Kept separate from customer sign-ups and not included in Thompsons For Travel customer communication.

That's it: two lists. Everything else is done with themes and fields, which become saved views in Fresh rather than lists to look after.

We keep all 14 ticks exactly as the customer chose them, but group them into six themes that suit the way Thompsons For Travel sells. A theme can be used as a group when needed, and nobody has to manage 14 audiences.

Package link on every enquiry

The consultant should never have to search the website to see what the customer was looking at. The package link arrives two ways:

Dedicated field

Package Link

A clickable link field near the top of the enquiry, next to the Package Reference. One click opens the package with its inclusions, pricing, kids pricing and travel window.

Note

Enquiry summary note

Zapier also adds a short note to the enquiry timeline with the package name, link, travel dates, travellers and the customer's message, so everything is in one place at a glance.

Clean link

Opens the package, not the form

Form links end in "/enquire". Zapier removes that so the link opens the package page itself.

Example summary note

Website enquiry: Pearle Beach Resort & Spa
Reference: PP-TH10060577
Link: thompsons.co.za/holiday-packages/4-pearle-beach-resort-and-spa-mauritius-package-7-nights-1/PP-TH10060577
Travel: 12 Mar 2027 to 19 Mar 2027 (flexible)
Departing: Johannesburg
Travellers: 2 adults, 2 children (7, 11)
Message: Would like a sea view room if possible

If a package is later removed from the site, the reference number and the summary note still show what the customer asked about, so nothing is lost.
